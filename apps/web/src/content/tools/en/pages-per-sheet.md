Use this tool to print multiple PDF pages on one sheet. For each PDF you add, it creates a new A4 file with 2, 4, 6, 9 or 16 original pages on each sheet.

Pages are arranged from left to right, then from top to bottom. Two-page and six-page layouts use landscape sheets. Four-page, nine-page and sixteen-page layouts use portrait sheets.

The new PDF keeps text selectable, but annotations, form fields and digital signatures do not carry over. Processing happens locally in your browser.

If you would rather set up the layout when you print, see Adobe's guide to [printing multiple PDF pages on one sheet](https://helpx.adobe.com/acrobat/desktop/print-documents/set-up-and-print-pdfs/multiple-pages.html).

## Holy PDF est-il gratuit ?

Oui. Les outils du site sont gratuits, sans limite cachée et sans filigrane.

## Faut-il créer un compte ?

Non. Ouvrez un outil, déposez vos fichiers, récupérez le résultat.

## Mes fichiers sont-ils envoyés sur un serveur ?

Non. Ils sont traités dans votre navigateur, sur votre appareil, et ne le quittent jamais. [Comment ça marche, et comment le vérifier](/fr/blog/vos-pdf-restent-sur-votre-appareil).

## Quels navigateurs ?

Les versions récentes de Chrome, Edge, Firefox et Safari, sur ordinateur comme sur téléphone. Le site a besoin de JavaScript et de WebAssembly, que tous ces navigateurs proposent.

## Ça marche sur téléphone ?

Oui, dans le navigateur du téléphone, sans appli à installer. Sur un très gros fichier, un téléphone peut être plus lent qu'un ordinateur : tout le travail se fait sur l'appareil.

## Y a-t-il une taille maximale ?

Le site n'impose pas de limite de taille. Le moteur travaille dans la mémoire du navigateur, qui a la sienne : un très gros fichier peut échouer, surtout sur téléphone. Sur un ordinateur récent, fusionner dix fichiers de 50 pages prend moins de deux secondes.

## Une signature faite avec Holy PDF a-t-elle une valeur légale ?

Signer pose une image de votre signature dans le PDF : c'est une signature électronique simple. Elle vaut pour les documents courants, quand les parties l'acceptent. Ce n'est pas une signature qualifiée au sens du règlement eIDAS, et elle ne la remplace pas là où la loi en exige une.

## Existe-t-il une appli ?

Pas encore. Une appli de bureau pour Mac et Windows, puis Linux, est en préparation, bâtie sur le code du site, avec la même promesse : vos fichiers restent sur votre appareil. Voir [les applis](/fr/applis).

## Le code de Holy PDF est-il ouvert ?

Oui. Le code du site est publié sous licence libre AGPL-3.0-or-later sur [GitHub](https://github.com/Snouzy/holy-pdf). Vous pouvez aussi vérifier la promesse sans lire une ligne de code. Ouvrez l'onglet Réseau des outils de développement de votre navigateur, lancez un outil, et regardez : aucune requête n'emporte votre fichier.

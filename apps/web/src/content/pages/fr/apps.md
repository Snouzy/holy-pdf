<h2 id="mac">Holy PDF pour Mac et Windows, puis Linux</h2>

Une appli de bureau est en préparation, pour Mac et Windows, puis Linux. Elle est bâtie sur le code du site : les mêmes outils, les mêmes moines, le même moteur. Et la même promesse : vos fichiers restent sur votre appareil.

Elle apportera ce que le site ne peut pas faire : ouvrir un PDF d'un double-clic, traiter un dossier entier, enregistrer sur place, travailler sans connexion.

Le code du site est publié sous licence libre AGPL-3.0-or-later sur [GitHub](https://github.com/Snouzy/holy-pdf). L'appli vivra dans le même dépôt.

<h2 id="iphone">Holy PDF pour iPhone</h2>

Une appli iPhone viendra après celle du bureau, avec la caméra pour le Scanner. En attendant, le site marche dans Safari sur iPhone, [Scanner](/fr/scanner) compris.

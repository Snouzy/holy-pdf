## Écrire

Une seule adresse : [hello@holy-pdf.com](mailto:hello@holy-pdf.com).

## Signaler un bug

Pour que je puisse reproduire le problème, indiquez :

- le navigateur et sa version (Chrome 131, Safari 18…) ;
- l'appareil (ordinateur, téléphone) ;
- l'outil utilisé ;
- les étapes, dans l'ordre, et le message affiché.

## Ne joignez jamais un document personnel

Il n'en faut pas pour vous aider. Décrivez plutôt le fichier : son nombre de pages, son poids, son origine (scan, export Word, photo). Une capture d'écran aide aussi, si aucun document personnel n'y apparaît.

## Une idée d'outil

Un outil vous manque ? Dites-le. Vos messages aident à choisir les prochains moines.

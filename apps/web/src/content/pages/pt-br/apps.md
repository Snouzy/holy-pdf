<h2 id="mac">Holy PDF para Mac e Windows; depois, Linux</h2>

O aplicativo para computador está em desenvolvimento para Mac e Windows e, depois, para Linux. Ele usa o mesmo código do site, com as mesmas ferramentas, os mesmos freis e o mesmo mecanismo. A promessa também é a mesma: seus arquivos permanecem no dispositivo.

O aplicativo oferecerá recursos que o site não pode fornecer, como abrir um PDF com dois cliques, processar uma pasta inteira, salvar no local escolhido e trabalhar offline.

O código do site é software livre, publicado sob a licença AGPL-3.0-or-later no [GitHub](https://github.com/Snouzy/holy-pdf). O aplicativo ficará no mesmo repositório.

<h2 id="iphone">Holy PDF para iPhone</h2>

O aplicativo para iPhone virá depois da versão para computador e usará a câmera para digitalizar documentos. Até lá, o site funciona no Safari do iPhone, inclusive para [digitalizar para PDF](/pt-br/digitalizar-para-pdf).

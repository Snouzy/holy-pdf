<h2 id="mac"> Holy PDF para Mac e Windows, em seguida, Linux</h2>

Um aplicativo de desktop está em funcionamento, para Mac e Windows, em seguida, Linux. É construído no código do site: as mesmas ferramentas, os mesmos monges, o mesmo motor. E a mesma promessa: seus arquivos permanecem em seu dispositivo.

Ele trará o que o site não pode: abrir um PDF com um duplo clique, processar uma pasta inteira, salvar no lugar, trabalhar offline.

O código do site é software livre, publicado sob a licença AGPL-3.0 ou posterior em [GitHub](https://github.com/Snouzy/holy-pdf). O aplicativo viverá no mesmo repositório.

<h2 id="iphone">Holy PDF para iPhone</h2>

Um aplicativo para iPhone virá após o desktop, com a câmera para o scanner. Até lá, o site funciona no Safari no iPhone, incluindo [Scanner](/pt-br/digitalizar-documento).

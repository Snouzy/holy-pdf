## Write

One address: [hello@holy-pdf.com](mailto:hello@holy-pdf.com).

## Report a bug

So that I can reproduce the problem, tell me:

- the browser and its version (Chrome 131, Safari 18…);
- the device (computer, phone);
- the tool you used;
- the steps, in order, and the message shown.

## Never attach a personal document

You do not need one to get help. Describe the file instead: its number of pages, its size, where it comes from (scan, Word export, photo). A screenshot helps too, as long as no personal document shows in it.

## An idea for a tool

Missing a tool? Say so. Your messages help choose the next monks.
